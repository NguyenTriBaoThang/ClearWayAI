## 🏷️ Brand Identity & Specifications

### 1. Official Logo (`assets/branding/clearway-logo.jpg`)
- **Dimensions:** 1024 × 1024 px (Square)
- **Palette:** Cyber Blue (`#00e5ff`), Electric Cyan (`#38bdf8`), Deep Navy (`#0a1128`, `#0b132b`), Emergency Siren Red/White (`#ef4444`).
- **Elements:**
  - Dynamic "CA" highway monogram with embedded urban skyline.
  - Emergency ambulance vehicle on high-speed priority lane with glowing forward directional chevron arrows.
  - Microchip circuit traces symbolizing edge AI computation and V2X IoT coordination.
  - Distinctive "ClearWay AI" modern geometric typography.

### 2. Official Hero Banner (`assets/branding/clearway-banner.jpg`)
- **Dimensions:** 1100 × 370 px (Ultrawide)
- **Usage:** Root README header, release announcements, technical documentation cover, slide decks.
- **Visuals:**
  - Traffic Operations Center (TOC) with live video wall and operator desks.
  - Isometric cyber arterial corridor with coordinated emergency ambulance green wave.
  - Live analytics panels: Network Flow (+18%), Avg Delay (-19%), Throughput (+15%), Adaptive Signal Phase Indicators, and Digital Twin Topology.

### 3. UI Reference Target (`assets/reference/dashboard-target.png`)
- **Dimensions:** 1254 × 1254 px
- **Purpose:** Visual and architectural blueprint used to baseline UI layout and widget styling.
